# 设备上位机场景检查

在规格中记录适用项、当前证据和验证方式；不适用项简述原因即可。

## 状态机和流程

明确状态、事件、迁移条件和动作完成信号；检查并发、乱序、重复通知、步骤重复/遗漏和等待超时。检查暂停、停止、急停、掉电后的恢复位置，区分“命令发送成功”和“设备动作完成”。检查手动与自动、站间资源互斥、恢复后动作幂等性。

## 通信

明确连接状态与设备可执行状态的区别；检查消息关联、半包粘包、校验、重复帧、迟到响应、超时和重试上限。重连后重新同步状态；会造成真实动作的命令不得盲目重发。用协议回放、仿真或已脱敏日志验证，接入现场设备须处于用户授权范围。

## 报警和联锁

明确触发、保持、清除、复位和恢复条件；检查上位机保护与硬件保护边界。不得用屏蔽报警或绕过联锁解决正常流程问题。故障时状态与 UI 应保持一致，恢复不能跳过必要确认或自动产生危险动作。

## 配方和参数

区分 UI 编辑值、持久化值、下发值与设备生效值；检查单位、范围、精度、默认值、版本和生效时机。校验批量下发的部分失败、回滚、运行中修改权限以及批次追溯；保留失败前后证据。

## UI/HMI

检查按钮权限与真实设备状态、忙闲和联锁条件一致；防止重复点击和跨线程刷新造成误操作。明确进行中、成功、失败和状态未知的反馈，断线时不要保留误导性的正常状态。使用现有设计模式和文案约定。

## 验证边界

分别标记静态检查、单元测试、仿真回放、台架测试和现场验证。软件测试不能证明机械安全；缺少设备时提供可执行现场验收项，不能将其标记完成。
