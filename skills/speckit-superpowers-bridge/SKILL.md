# 规格到实现交接

读取当前任务规格、计划和任务状态。检查目标、范围、验收条件、关键失败处理是否足以实施；缺少会影响行为的内容时先补规格。采用 `../superpowers/SKILL.md` 的实现和排错纪律，不重新开展无必要的产品讨论。

编辑前阅读目标代码及最相近的现有实现；遵循其命名、目录、日志、配置访问、错误处理和测试习惯。复用现有抽象，控制变更范围。

逐项完成任务并记录对应需求和验证证据。若代码事实使设计必须改变，先在任务文档说明原因及影响，再实施一致的变更。超出授权目标或需要真实外部副作用时，完成可独立进行的准备后报告所缺授权。

不能仅凭“代码已写完”标记完成；检查原始验收、回归和未执行项目。产物位置沿用 `../max-mode-cn/SKILL.md`。
