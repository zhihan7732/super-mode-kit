# 超级模式入口

使用本包的高严谨度工作流。先识别用户是在咨询、诊断、评审还是要求修改；按所请求的行为完成工作，不能把诊断自动扩大为代码修改。

## 定位与配置

以当前 `SKILL.md` 的父目录为本技能目录，其父目录为技能根目录。所有兄弟技能均相对此根定位，不依赖固定盘符或当前 shell 工作目录。

读取本目录 `settings.json`；没有配置时使用：中文产物、当前用户 Documents/CodexPlans 作为产物根目录。`artifact_root` 为空也使用该默认值；非空必须为绝对路径。无法取得 Documents 时使用用户目录下的 CodexPlans。无效 JSON 或无效路径须说明并修复配置，不能静默改写到未知目录。用户任务中指定的位置优先；项目根规则优先于默认约定。

产物写入 `<artifact_root>/<项目名>/specs/<任务名>/`。项目名从仓库推断，任务名用稳定短名；替换路径分隔符、控制字符和 Windows 保留字符，防止名字越出根目录。目录已有同名任务时检查内容，避免覆盖其他任务。

## 依赖交接

依次读取兄弟目录 `pc-control-max-mode/SKILL.md`、`speckit/SKILL.md`、`speckit-superpowers-bridge/SKILL.md` 和 `superpowers/SKILL.md`。需要额外交付检查时再读取 `gstack/SKILL.md`。

缺失依赖时明确给出技能名和缺失路径，提示从完整安装包重新安装；可以继续只读分析，但不能声称完整工作流已加载。不得联网自动安装同名上游项目来代替本包说明。

对 CT-1131A 等特定项目，仅在知识技能/数据可用且用户任务需要时按其说明只读查询，并用当前源码和日志验证历史结论。缺失项目数据库不阻塞通用流程；不要虚构查询结果或默认向数据库写回。
